# TAB Business

Отдельный корпоративный контур платформы TAB для мониторинга психологической безопасности, эмоционального климата и организационных рисков.

Этот репозиторий физически отделён от образовательного проекта «Вместе против травли» и не должен объединяться с его кодовой базой.

## Текущий статус

- демонстрационный прототип;
- employee interface;
- weekly pulse survey;
- безопасный канал обратной связи;
- HR Dashboard;
- AI-аналитический отчёт.

## Принцип архитектуры

TAB Business разворачивается как самостоятельный продуктовый контур. Общие подходы и инфраструктурные решения могут переиспользоваться, но данные сотрудников, роли, интерфейсы и бизнес-логика не смешиваются с образовательным контуром.
