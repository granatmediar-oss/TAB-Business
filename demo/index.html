Принцип pulse

Каждую неделю активируется одна тема. Движок остаётся единым, меняется только набор вопросов.

12 недель = один цикл.

Принцип конфиденциальности

Анонимность — отдельный режим хранения и выдачи данных.
Руководители не получают персональные pulse-ответы по умолчанию.
Для малых групп применяется порог агрегации.
